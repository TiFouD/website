Bienvenue sur le code source de mon portfolio personnel. Ce site statique me sert de vitrine pour présenter mes compétences en **Cybersécurité**, **DevOps** et **Développement**.

🔗 **Voir le site en ligne :** [https://tifoud.github.io/](https://tifoud.github.io/)

## 🛠️ Stack Technique

Ce projet est conçu pour être léger, rapide et maintenable sans framework lourd.

* **Frontend :** HTML5 Sémantique, CSS3 (Variables & Flexbox/Grid), JavaScript (Vanilla).
* **Design :** Responsive (Mobile First) & Support du **Dark Mode** 🌙.
* **Fonctionnalités :** Diagrammes d'architecture (Mermaid.js), animations CSS.
* **Déploiement :** GitHub Pages (CI/CD).
